# Certified Kubernetes Administrator

Bem-vindo à documentação de estudos para a certificação
**Certified Kubernetes Administrator (CKA)**.

Este portal reúne conteúdos técnicos, explicações,
comandos, exemplos práticos e laboratórios relacionados
à administração de clusters Kubernetes.

## Objetivo

Organizar os estudos de maneira estruturada,
facilitando a consulta e a revisão dos principais
conceitos do Kubernetes.
